在本机整理曲名、专辑序号和平台链接。导出 JSON 经维护者审核后发布，地图站只读取静态映射。

音频身份绑定

只有明确的媒体 ID 或原始文件名绑定，才能在精简导出中替换本地音频。关联一个事件不会把它的所有候选都认作同一首歌。

平台播放

请填含歌曲 ID 的完整链接；短分享链接请打开后复制完整链接。播放器使用平台外链，平台可能限制部分曲目或地区。

发布流程
  1. 导出当前条目提案，交由社区或维护者审核；本页面不上传数据。
  2. 维护者合并后，将完整映射保存为 webui/overrides/music_bindings.json。
  3. 运行音乐地图构建命令，或发布工具生成的静态映射；静态地图无需数据库或账户系统。
